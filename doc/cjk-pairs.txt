==============================================================================
1. Install                                                  *cjk-pairs-install*

Use any plugin manager. With lazy.nvim: >

    { 'phakeandy/cjk-pairs.nvim', opts = {} }
<

==============================================================================
2. Setup                                                     *cjk-pairs-setup*

Call |cjk-pairs.setup()| once. Calling it again re-installs the mappings.

==============================================================================
3. Keys                                                      *cjk-pairs-keys*

The text object keys are the builtin ones, and stay the builtin ones: >

    i(  i)  ib      ( )  （ ）
    i[  i]          [ ]  【 】  〖 〗  〔 〕  ［ ］
    i{  i}  iB      { }  ｛ ｝
    i<  i>          < >  《 》  〈 〉  ＜ ＞
    i"              " "  “ ”  ＂ ＂  「 」  『 』
    i'              ' '  ‘ ’  ＇ ＇
    i`              ` `
<
The `a` variants exist for every key and include the pair itself.

==============================================================================
4. Options                                                 *cjk-pairs-options*

                                                        *cjk-pairs.setup()*
cjk-pairs.setup({opts})

{opts} is a table:

    families      Table. Key is a text object key, value is a list of
                  `{ open, close }` pairs that key accepts. A key that
                  already exists is replaced, a new key adds a new text
                  object. `false` disables the key.

    matchpairs    List. Entries are appended to 'matchpairs', so `%` jumps
                  between them too. Empty by default.

==============================================================================
5. Limits                                                  *cjk-pairs-limits*

Quote-like pairs are searched on the current line only, as the builtin ones
are. A `“…”` split over two lines is therefore not selected.

Pressing `i"` a second time in Visual mode does not extend the selection to
the quotes as the builtin does; use `a"`.
